# Algoritmos 2026 - Trabajos Prácticos

Repositorio para almacenar los trabajos prácticos de la cursada de Algoritmos 2026. Contiene código reutilizable en la carpeta `common/` y TPs organizados por carpeta.

## Estructura del Repositorio
- `common/`: Código compartido entre múltiples proyectos (ej: TDAs básicos como `Stack.py`).
- `tp_XX/`: Carpeta por trabajo práctico, con:
  - `consigna.md`: Obligatorio, contiene la consigna del TP (seguir sus indicaciones para los ejercicios).
  - `ejXX.py`: Ejercicios resueltos, nombrados según la numeración de la consigna.

## Convenciones
1. Seguir estrictamente la consigna detallada en `tp_XX/consigna.md` para cada TP.
2. Importar TDAs y código reutilizable desde `common/` en lugar de reescribirlos.
3. Mantener nombres de archivos de ejercicios consistentes con la numeración de la guía (ej: `ej5.py`, `ej22.py`).

## Archivos Ignorados
Consultar `.gitignore` para la lista de archivos y carpetas que no se suben al repositorio (caches de Python, configuraciones de IDE, archivos de sistema, etc.).

Ver [COMMITS.md](COMMITS.md) para la convención de commits utilizada en este repositorio.
